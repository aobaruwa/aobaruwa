## 🚀 A little about me

I'm a software engineer and data/ML practitioner with experience across
**Microsoft, Scale AI, KPMG, and Interswitch**. My work spans production
backend systems, machine learning, data pipelines, security analytics,
and LLM-powered automation.

-   🤖 **Applied AI:** LLM agents, reinforcement learning from human
    feedback (RLHF), NLP, and model evaluation.
-   🧠 **Machine learning:** Graph neural networks, anomaly detection,
    clustering, and deep learning.
-   ⚙️ **Backend & systems:** Automation, APIs, distributed systems,
    CI/CD, and cloud-based services.
-   📊 **Data engineering:** ETL pipelines, SQL analytics, and turning
    noisy data into useful signals.
-   🎓 **Education:** M.S. in Computer Science, University of Oregon.
-   🌎 **Based in:** Vancouver, Canada.

> **My engineering philosophy:** make it useful, make it measurable, and
> make it reliable.
